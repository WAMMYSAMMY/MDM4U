1.1 - Représentation des données

Les différents types de données

Variable Quantitative (continue et discrète)

Une variable quantitative est une variable qui peut être exprimée par un nombre, une quantité. Une variable continue est une variable qui peut prendre toutes les valeurs possibles d'un intervalle de nombres réels. Une variable discrète est une variable qui peut prendre uniquement certaines valeurs d'un intervalle de nombres réels. Généralement, les valeurs admissibles ne sont que les nombres entiers.

Variable Qualitative (nominale et ordinale)

définition et exemples de variables qualitatives Une variable qualitative, ou variable catégorielle, est un type de variable qui mesure une qualité d'un individu statistique. Elle peut être de type nominal (catégorielle) ou ordinal. Les variables qualitatives nominales, comme le sexe ou la couleur des yeux, ne ont pas d'ordre spécifique. Les variables qualitatives ordinales, comme le niveau de satisfaction, ont un ordre défini parmi les catégories possibles.

Certains types de diagrammes

Diagramme à bandes

Un diagramme à bandes représente des données à l’aide de bandes de même largeur. La hauteur ou la longueur de chaque bande correspond à la valeur représentée. Il sert surtout à comparer différentes catégories entre elles. Exemple : On veut comparer le nombre d’élèves qui préfèrent différents sports : Soccer : 30 élèves Basketball : 20 élèves Volleyball : 15 élèves Hockey : 10 élèves On utiliserait un diagramme à bandes pour voir rapidement quel sport est le plus ou le moins populaire.

Histogramme

Un histogramme représente la répartition de données numériques en les regroupant dans des intervalles. Les bandes se touchent parce que les données représentent des valeurs continues. Exemple : On veut montrer la répartition des notes d’un test dans une classe : 50–59 % : 2 élèves 60–69 % : 5 élèves 70–79 % : 10 élèves 80–89 % : 8 élèves 90–100 % : 3 élèves L’histogramme permet de voir où se concentrent les résultats et comment les notes sont réparties.

Diagramme circulaire

Un diagramme circulaire est un cercle divisé en plusieurs sections. Chaque section représente une proportion ou un pourcentage du total. La taille de chaque section dépend de sa proportion. Exemple : Une enquête demande aux élèves comment ils se rendent à l’école : Auto : 40 % Autobus : 30 % Marche : 20 % Vélo : 10 % Le diagramme circulaire permet de voir facilement quelle proportion du groupe utilise chaque moyen de transport.

Diagramme à ligne brisée

Un diagramme à ligne brisée représente des données avec des points reliés par des lignes. Il est particulièrement utile pour montrer l’évolution d’une donnée au fil du temps. Exemple : On veut suivre la température pendant une semaine : Lundi : 15 °C Mardi : 18 °C Mercredi : 20 °C Jeudi : 17 °C Vendredi : 22 °C On utiliserait un diagramme à ligne brisée pour voir comment la température augmente ou diminue au cours de la semaine.
